# 13. Glossaire

> Ce chapitre rassemble les mots employés dans le manuel, avec leur sens dans Open Notebook.
> **Point de départ** : aucun ; à consulter à tout moment.
> **Durée** : à la demande. **Avant** : rien.

## Ce qu'il faut savoir

Les libellés de l'interface sont cités entre guillemets, tels qu'ils s'affichent en français. Les termes techniques communs à toute la série de manuels sont aussi dans le [glossaire général](../../glossaire.md).

## Mots de l'interface

| Mot | Sens |
|---|---|
| Analyse (insight) | résultat d'une transformation appliquée à une source, rangé dans l'onglet « Analyses » de la source |
| Archiver | ranger un carnet hors de la liste des carnets actifs, sans le supprimer |
| Attributions des modèles par défaut | réglage qui dit quel modèle sert à quoi : discuter, transformer, chercher par le sens, transcrire l'audio, lire les podcasts |
| Carnet | dossier de travail qui réunit des sources, des notes et des conversations sur un même sujet |
| Citation | renvoi vers la source qui justifie une phrase de la réponse ; un clic ouvre la source |
| Contexte | ce qui est envoyé au modèle à chaque question : consignes, sources choisies, notes, historique ; le bas de la colonne de conversation en donne la taille |
| Contenu complet | mode d'une source : son texte entier est envoyé au modèle à chaque question |
| Demander | question posée à tous les carnets (ou à un seul) : l'application cherche elle-même les passages utiles par le sens, puis rédige une réponse |
| Embedding | représentation du sens d'un passage sous forme de nombres ; deux passages de sens voisin ont des embeddings voisins ; sert à la recherche par le sens |
| Fournisseur | service qui fait tourner les modèles d'IA ; ici « OpenAI Compatible », qui désigne le service LLM central |
| Jeton | unité de texte comptée par le modèle, environ trois quarts de mot en français |
| Modèle de langage | modèle d'IA qui rédige les réponses ; ici `chat` |
| Modèle d'embedding | modèle d'IA qui calcule les embeddings ; ici `embed` |
| Note | texte gardé dans le carnet : écrit à la main, réponse enregistrée ou analyse |
| Podcast | épisode audio généré à partir d'un carnet, avec une ou plusieurs voix de synthèse |
| Profil d'épisode, profil d'intervenants | réglages d'un podcast : plan, langue, nombre de parties ; voix et personnalité de chaque intervenant |
| Recherche textuelle | recherche par mots exacts |
| Recherche vectorielle | recherche par le sens, à partir des embeddings ; trouve aussi les reformulations et les autres langues |
| Réflexion | texte intermédiaire que le modèle `chat` écrit pour lui-même avant de répondre ; invisible, mais il prend du temps |
| Service LLM central | service installé à part qui fait tourner les modèles d'IA pour toutes les applications de la machine, sous les noms fixes `chat`, `embed`, `rerank` et `transcribe` |
| Session | une conversation d'un carnet ; chaque carnet peut en garder plusieurs |
| Source | document ajouté à un carnet : fichier, lien web, texte collé, audio ou vidéo |
| Synthèse vocale, transcription | lecture d'un texte par une voix de synthèse ; passage de la parole au texte |
| Transformation | consigne réutilisable appliquée à une source : résumé, points clés, table des matières… |
